Included files
--------------
placeprep-logo.svg             Full horizontal logo, scalable vector

placeprep-logo-compact.png     Compact logo PNG
placeprep-icon.svg             Square brand icon, scalable vector

favicon.svg                    Same scalable icon for browsers
favicon.png                    512x512 favicon PNG
favicon.ico                    Multi-size browser favicon
placeprep-logo-monochrome.svg  Single-color logo for print/one-color use

Suggested website setup
-----------------------
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="icon" type="image/png" sizes="512x512" href="/favicon.png">
<link rel="shortcut icon" href="/favicon.ico">

Use the SVG files for crisp scaling. Use the compact logo in narrow headers.
Use the square icon for app icons, avatars, and favicon. Use the monochrome
version when printing in one color.

All assets are original PlacePrep brand artwork created for this request.
